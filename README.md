# Spaceship Titanic Survival Prediction Model

A machine-learning notebook that predicts the survival of Spaceship Titanic passengers based on a kaggle dataset. 

## What it does

- Builds a preprocessing pipeline which cleans data, imputes missing information, and drops unneeded categories
- Trains, tests, and cross-validates multiple classification models (Logistic Regression, Random Forest, and HistGradientBoostClassifier) to determine which has the greatest prediction accuracy
- Trains a HistGradientBoostClassifier production model on the full kaggle dataset to generate predictions
  
Dataset used: https://www.kaggle.com/competitions/spaceship-titanic/data
